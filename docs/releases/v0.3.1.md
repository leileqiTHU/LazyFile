# LazyFile 0.3.1 — independent assistant profile

Windows 10/11 x64 preview. Download LazyFile-0.3.1-windows-x64-setup.exe below.

The Codex app-server engine remains included; no separate Codex installation is required. LazyFile now keeps configuration, authentication and runtime data in its own CodexHome folder. It does not inherit your Codex/OpenAI environment overrides or use your existing Codex login. Credentials use the private file store instead of a shared keyring.

**Upgrade:** sign in with ChatGPT again inside LazyFile. No existing Codex credentials are copied. Your LazyFile library and authorized folders are preserved. Local search works without login; its approximately 865 MB model download is automatic on first setup.

Unsigned preview: Windows may show an unknown-publisher warning. macOS is not included. Very small libraries may have no pure semantic results due to DigUp's relevance threshold; keyword search remains available.
