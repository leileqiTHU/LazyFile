# LazyFile 0.3.0 — guided Windows setup

## Install and start searching

Download **LazyFile-0.3.0-windows-x64-setup.exe** below. This release is for 64-bit Windows 10/11.

1. Run the installer and choose where to install. It installs for your Windows account.
2. Open LazyFile. The welcome guide automatically downloads and verifies the local search models (about 865 MB, once). Keep the app open and connected to the internet. Retry resumes an interrupted download.
3. While it downloads, add folders to search. Observation folders stay read-only; a workspace is optional for receiving and organizing files.
4. Start searching. The initial index runs locally; semantic results become available as indexing completes.

The DigUp search engine and Codex runtime are included. No Node.js, Python, terminal commands, separate Codex installation or manual model download is required. Local search works offline after setup. Sign in with ChatGPT only if you want the assistant; relevant file content is processed by OpenAI, subject to your account access and usage limits.

This is an **unsigned preview**: Windows may display an unknown-publisher warning. macOS installers are not included in this release. The adjacent `SHA256SUMS.txt` verifies the downloaded installer; it is not a code-signing certificate.

Existing authorized folders and library data are preserved. New installations use per-user application storage. Setup can be reopened from Settings.

Known limitation: purely semantic queries can return no matches in very small libraries because of DigUp’s statistical relevance threshold. Keyword search and assistant folder browsing remain available.

## 安装后按引导使用

下载下方 **LazyFile-0.3.0-windows-x64-setup.exe**，适用于 64 位 Windows 10/11。

1. 运行安装包，选择安装目录，为当前 Windows 用户安装。
2. 打开 LazyFile，欢迎引导会自动下载并校验约 865 MB 的本地模型，仅需一次。保持应用打开和联网，下载中断后可重试继续。
3. 下载期间添加需要搜索的文件夹。仅观察文件夹保持只读；需要接收和整理文件时，可另选工作空间。
4. 开始查找。首次索引在本机进行，语义结果会随索引完成逐步补齐。

已内置 DigUp 搜索引擎和 Codex，无需另装 Node.js、Python 或命令行工具，也无需手动下载模型。本地搜索准备好后可离线使用；智能助手需要登录 ChatGPT，相关文件内容发送给 OpenAI，并受账户权限及额度限制。

当前是**未签名的预览版**，Windows 可能显示未知发布者提示。本次只发布 Windows 安装包。`SHA256SUMS.txt` 用于校验安装包，不代表代码签名。已有文件库和授权范围会保留，设置中可重新打开引导。
已知限制：文件库很小时，DigUp 的统计相关性阈值可能使纯语义查询没有结果；仍可使用关键词搜索或让助手浏览文件夹。
