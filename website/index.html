Before you download

What is LazyFile?

LazyFile is an open-source desktop file search app. It combines local semantic and keyword search with an optional AI assistant that can browse and read authorized files.

Is LazyFile free?

LazyFile is MIT-licensed and available to download without a LazyFile subscription. Local search requires no ChatGPT account. Assistant access depends on your ChatGPT account permissions and usage limits.

Does it work on macOS?

The current installer supports 64-bit Windows 10/11. macOS is a development target; a tested Mac installer is not available yet.

Are my files uploaded?

Local quick search runs on your computer. Using the assistant or AI file understanding sends relevant text, images and tool results to OpenAI. Observation folders are read-only.

Do I need to install Codex or download models myself?

No. The app includes its assistant engine, and the welcome guide downloads local search models automatically. Sign in separately inside LazyFile for the assistant.

What can it search, and what are the limits?

The DigUp engine indexes supported documents, images, audio, video and code. The inventory scans up to 5,000 files per root. Assistant text extraction is capped at 60,000 characters and 40 PDF pages. Chat understanding of audio/video is metadata-only. Very small libraries may have no pure semantic matches; try exact words or assistant browsing.

Will it move my original files?

Observation folders are never modified. Files sent into the optional workspace are copied, preserving the originals. If autonomous organization is enabled, the assistant can move workspace files, with an operation history and conditional undo.
