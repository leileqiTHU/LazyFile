# LazyFile

**记得内容，忘了文件名？也能找回来。**

LazyFile 是一个专注文件查找的桌面工具。描述你想找的内容、输入准确的关键词，或者让智能助手浏览文件夹、阅读文件，帮你确认结果。

## 按你记得的方式找文件

- **「上个季度的预算。」** 忘记文件名时，按内容和含义搜索。
- **「Invoice 2026-1042。」** 用准确的编号、名称或短语匹配文件名和提取出的正文。
- **「湖边木屋的夏日度假。」** 用中文查找一份描述高山湖畔假期的英文笔记。
- **「找到批准的预算，确认一下总金额。」** 让助手搜索、浏览相关文件夹，并阅读原文后回答。

快捷搜索结合本地语义检索与关键词匹配，由 [DigUp](https://github.com/ARahim3/DigUp) 和 EmbeddingGemma 2 提供支持。在 Windows 的其他应用中按 **Ctrl + Shift + Space** 唤出，或在 LazyFile 内按 **Ctrl + K** 打开。

智能助手可以结合搜索结果、目录说明和文件内容逐步查找，根据发现缩小范围。结果会关联真实文件，方便你预览、打开或在文件夹中定位。

## 文件夹用途明确，权限也明确

LazyFile 只有两种用户文件夹：

| 文件夹 | LazyFile 可以做什么 |
| --- | --- |
| **仅观察文件夹**——可以有多个 | 读取和搜索。文件留在原处，LazyFile 不会修改它们。 |
| **LazyFile 工作空间**——只有一个 | 读取、搜索，并整理你交给它的文件。 |

搜索默认覆盖**全部授权文件夹**，也可以限定为工作空间，或授权范围内的某个文件夹。只想搜索时，添加仅观察文件夹即可；需要发送文件让助手整理时，再设置工作空间。

把文件发送给助手后，LazyFile 会将副本放进工作空间，保留原文件。开启自主整理时，助手会选择合适的位置，按需创建子文件夹；缺少影响决定的重要信息时，再向你提问。移动操作有记录，在文件未被修改且不存在位置冲突时可以撤销。

工作空间的普通目录会维护两份简短说明：`.overview.md` 和 `.intro.md`，帮助助手理解目录内容、逐层寻找。代码仓库和软件包保持完整；仅观察文件夹不会被写入新的目录说明。

## 本地搜索，按需使用云端助手

**快捷搜索在你的电脑上运行。** 搜索索引和向量模型推理留在本地。下载搜索模型后，不登录 ChatGPT 也能使用快捷搜索。

**智能助手通过 Codex 使用你的 ChatGPT 账户。** 任务中需要的文本、图片和工具结果会发送给 OpenAI 处理；连接账户后进行的自动文件理解也适用这一点。助手受账户可用权限和额度限制，不是完全离线功能。

助手只能访问你授权的文件夹。发送一个文件，不会授予它浏览该文件原始父目录的权限。

## 开始使用

LazyFile **0.2 目前是早期预览版**。已在 Windows 上验证；macOS 是目标平台，尚未完成 Mac 实机验证。界面支持英文和简体中文。

本仓库暂未发布安装包。需要运行当前预览版，请参阅[开发指南](docs/development.md)，从源码启动。

启动应用后：

1. **选择文件夹。** 添加仅观察文件夹用于搜索；需要接收和整理文件时，再选择一个工作空间。
2. **设置本地搜索。** 在设置中下载搜索模型，约 865 MB，只需下载一次。等待首次索引完成；新选择的搜索范围可能需要单独建立索引。
3. **开始查找。** 输入一段描述、文件名或准确短语，选中结果查看预览。
4. **需要时连接助手。** 安装 Codex CLI，在设置中检查已有登录或使用 ChatGPT 登录。让助手找文件、核实内容，或整理你发给它的文件。

| Windows 快捷键 | 功能 |
| --- | --- |
| `Ctrl + Shift + Space` | LazyFile 运行时，从其他应用打开快捷搜索 |
| `Ctrl + K` | 在 LazyFile 内打开快捷搜索 |
| `↑` / `↓` | 选择结果 |
| `Enter` | 打开选中的文件 |
| `Ctrl + Enter` | 在文件夹中显示 |
| `Esc` | 关闭快捷搜索 |

## 支持哪些内容

本地 DigUp 引擎可检索受支持的文档、图片、音频、视频和代码。智能助手可以读取文本文件、DOCX 和 PDF 提取出的文字，以及查看受支持的图片。

当前预览版有以下限制：

- 助手单文件文本提取上限为 60,000 字符，PDF 最多读取前 40 页。聊天中的音视频理解目前仅限元数据。
- 文件清单每个根目录最多扫描 5,000 个文件，跳过隐藏文件和依赖目录；扫描不完整时会提示。
- 工作空间整理是可选能力。关闭自主整理后，仍可搜索和理解文件，不会自动移动。
